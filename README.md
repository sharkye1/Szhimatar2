## 💡 О проекте

**Szhimatar** — это десктопное приложение для сжатия, конвертации видео и фоновой загрузки медиа. Оно работает полностью автономно на вашем компьютере с помощью FFmpeg и Rust-бэкенда.

### Почему это удобно:
- **🔒 Полная приватность и оффлайн**: видео обрабатывается исключительно локально на вашем устройстве, никакие данные никуда не отправляются.
- **🪶 Минимальное потребление памяти**: благодаря связке Tauri и Rust приложение запускается мгновенно и не расходует гигабайты RAM, в отличие от тяжелых Electron-приложений.
- **⚡ Параллельная работа с очередью**: можно одновременно задействовать мощности процессора и видеокарты для параллельного сжатия нескольких видео.
- **🎯 Экономия времени**: готовые ролики можно перетаскивать прямо из интерфейса приложения в мессенджеры (Telegram, Discord) или рабочие папки.

## 🔥 Ключевые возможности

- **⚡ Duo Mode (Параллельный CPU + GPU рендеринг)**  
  Умный планировщик очереди (`RenderScheduler`), позволяющий одновременно обрабатывать задачи в два потока: один ролик сжимается на видеокарте через аппаратные кодеки (NVENC / AMF / QuickSync), а второй — на процессоре (x264 / x265). Это позволяет утилизировать железо на 100% без простоев.

- **🖱️ Двусторонний Drag & Drop (включая Drag Out)**  
  - Быстрое добавление видео простым перетаскиванием файлов или папок в окно программы.
  - **Drag Out**: готовый сжатый файл можно прямо из карточки очереди перетащить мышкой в окно Telegram, Discord, браузер или проводник без необходимости вручную открывать папку с файлом.

- **🛡️ Process Management & Изоляция процессов**  
  Все дочерние процессы кодирования (FFmpeg) и загрузки (yt-dlp) работают через менеджер процессов и привязаны к **Windows Job Objects**. Это исключает зависание «зомби-процессов» в диспетчере задач при закрытии или отмене заданий. Поддерживается точечная пауза, возобновление и остановка конкретных задач.

- **👁️ Zero-Disk I/O быстрый предпросмотр**  
  Интерактивный просмотр кадров видео перед сжатием с генерацией кадров через потоковый пайп (`stdout pipe`) прямо в память — без создания временных файлов и лишней нагрузки на SSD/HDD.

- **📥 Встроенный медиазагрузчик (yt-dlp)**  
  Скачивание видео и аудио по ссылке с популярных видеохостингов прямо в приложении. Поддерживается выбор качества, извлечение звука в MP3, отдельная очередь загрузок и скрытый фоновый запуск без всплывающих черных консольных окон.

- **📊 Zero-Allocation парсер прогресса**  
  Потоковый парсер вывода FFmpeg на стороне Rust работает быстро и без аллокаций памяти, обеспечивая плавное обновление прогресс-бара, точный расчёт FPS, битрейта, итогового размера и оставшегося времени (ETA).

## ⚙️ Форматы и параметры сжатия

### Видео
- **Контейнеры**: MP4, MKV, AVI, MOV, WEBM, FLV, WMV, TS, MTS и др.
- **Кодеки**: H.264 (x264, NVENC, AMF, QSV), H.265 (HEVC), VP9, AV1.
- **Контроль качества**: CRF (Constant Rate Factor), целевой битрейт, пресеты скорости кодирования (от `ultrafast` до `veryslow`).
- **Трансформация**: изменение разрешения (от 144p до 4K / Ultrawide), частоты кадров (FPS), обрезка видео по таймлайну (Trimming), наложение водяных знаков (изображений с настройкой позиции, прозрачности и масштаба).

### Аудио
- **Кодеки**: AAC, MP3, Opus, FLAC или режим прямого копирования исходной дорожки (`copy`).
- **Параметры**: битрейт, каналы (Mono / Stereo), частота дискретизации, нормализация и громкость.

## 🎨 Интерфейс и кастомизация

- **Dynamic Island Header**: компактная плавающая панель с живым статусом очереди, прогрессом и быстрыми действиями.
- **15+ тем оформления**: Dark, Light, AMOLED Night, Nord, Catppuccin, Ocean, Synthwave и др.
- **Аппаратная подсветка (Vendor Auras)**: автоматическое определение вендоров CPU и GPU (Intel / AMD / NVIDIA) с адаптивной подсветкой акцентов интерфейса.
- **Менеджер пресетов**: сохранение любимых настроек сжатия в один клик и выбор пресета по умолчанию.
- **Мультиязычность**: поддержка интерфейса на Русском, English, 中文, Esperanto, Medžuslovjanski и др.
- **Performance Mode**: режим для слабых ПК с отключением ресурсоемких визуальных эффектов и размытий.
- **Статистика**: учет сэкономленного дискового пространства, история рендеров и графики сжатия.

## 🚀 Запуск и сборка

### Системные требования
- **Node.js** 18+ и **npm**
- **Rust** 1.70+ (устанавливается через [rustup.rs](https://rustup.rs/))
- **Windows**: Visual Studio C++ Build Tools (компоненты «Разработка классических приложений на C++»)
- **macOS**: Xcode Command Line Tools (`xcode-select --install`)
- **FFmpeg & FFprobe**: должны быть установлены в системе (в `PATH`) или указаны в настройках программы

### Поддержка платформ
- **Windows** (основная платформа): полная интеграция с Windows Job Objects, системным реестром для детекции вендоров CPU/GPU и контекстным меню Explorer.
- **macOS**: сборка `.app` и `.dmg` (включая настроенный GitHub Actions CI/CD workflow для Apple Silicon / ARM64), интеграция с Finder (`open -R`).
- **Linux**: базовая совместимость.

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/sharkye1/Szhimatar2.git
cd Szhimatar2
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run tauri dev
```

### 3. Сборка релизной версии
```bash
# Для текущей ОС (Windows: .msi/.exe, macOS: .app/.dmg)
npm run tauri build

# Сборка под macOS Apple Silicon (M1/M2/M3/M4)
npm run tauri build -- --target aarch64-apple-darwin
```
Собранные бинарники и установщики будут находиться в папке `src-tauri/target/release/bundle/` (или соответствующей target-папке).

### 4. Тестирование
```bash
# Тесты фронтенда и планировщика (Vitest)
npm run test

# Тесты бэкенда (Rust)
cd src-tauri
cargo test
```

## 📁 Хранилище данных

Все пользовательские конфигурации и история хранятся локально:
- **Windows**: `%USERPROFILE%\.szhimatar\` (обычно `C:\Users\<Имя_пользователя>\.szhimatar\`)
- **Linux/macOS**: `~/.szhimatar/`

```
.szhimatar/
├── logs/
│   ├── app.log              # Общий журнал приложения
│   └── renders/             # Логи отдельных заданий FFmpeg
├── stats/
│   └── stat.json            # История и статистика сжатий
├── presets/                 # Пользовательские пресеты
├── binaries/                # Локальные бинарники (yt-dlp и др.)
└── settings.json            # Настройки программы
```
