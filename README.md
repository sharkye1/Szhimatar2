## 💡 О проекте

**Szhimatar** — это быстрый, компактный и полностью оффлайновый компрессор видео с современным интерфейсом и глубокой интеграцией с операционной системой. Приложение построено на базе **Rust (Tauri)** и **React/TypeScript**, обеспечивая минимальное потребление оперативной памяти, мгновенный старт и параллельный рендеринг на нескольких вычислительных устройствах (CPU + GPU).

## ✨ Ключевые возможности

### 🚀 Рендеринг и сжатие
- **Поддержка всех популярных форматов**: MP4, MKV, AVI, MOV, WEBM, FLV, WMV, TS, MTS и др.
- **Широкий выбор кодеков**: H.264 (AVC), H.265 (HEVC), VP9, AV1, а также аппаратные кодеки NVENC (NVIDIA), AMF (AMD) и QuickSync (Intel).
- **Гибкий контроль качества**: CRF (Constant Rate Factor), целевой битрейт, пресеты кодирования (от ultrafast до slower), частота кадров (FPS) и разрешение (от 144p до 4K DCI / Ultrawide).
- **Настройка аудиодорожек**: кодеки AAC, MP3, Opus, FLAC или режим прямого копирования (`copy`), управление битрейтом, каналами (Mono/Stereo), частотой дискретизации и громкостью.
- **Обрезка видео (Trimming)**: установка начальной и конечной точки таймлайна прямо в карточке задачи перед запуском.
- **Наложение водяных знаков**: добавление изображений с выбором одного из 5 положений, настройкой прозрачности и масштаба.

### ⚡ Duo Mode & Аппаратное ускорение
- **Параллельный Duo-рендеринг**: одновременное распределение очереди сжатия между слотами CPU и GPU с помощью планировщика `RenderScheduler` — см. [DUO_MODE_GUIDE.md](DUO_MODE_GUIDE.md).
- **Мгновенная детекция оборудования**: сверхбыстрое определение вендоров CPU и GPU через системный реестр Windows (<0.3 мс вместо медленного `wmic`).
- **Hardware-зависимый UI**: динамические акцентные градиенты и ауры под цвета установленного железа (Intel / AMD / NVIDIA).
- **Hardware Override**: система эмуляции оборудования для проверки UI на любых связках CPU/GPU — см. [HARDWARE_OVERRIDE_QUICKSTART.md](HARDWARE_OVERRIDE_QUICKSTART.md).

### 📥 Встроенный медиазагрузчик (yt-dlp)
- **Загрузка по ссылке**: скачивание видео и аудио напрямую с YouTube и десятков других медиахостингов.
- **Выбор форматов**: скачивание в лучшем качестве MP4 или извлечение чистого звука в MP3.
- **Фоновая работа**: скрытый запуск без всплывающих черных консольных окон (`CREATE_NO_WINDOW`).
- **Своя очередь загрузок**: отслеживание прогресса, скорости, размера и отмена загрузок.

### 🛡️ Стабильность и Process Management
- **Управление процессами**: точечная пауза, возобновление и остановка конкретных задач очереди через `ProcessManager`.
- **Windows Job Objects**: дочерние процессы (FFmpeg, yt-dlp) изолированы в Job Object. Никаких «зомби-процессов» в диспетчере задач при закрытии или падении программы.
- **Zero-Allocation парсер прогресса**: потоковый парсинг `stderr` FFmpeg на Rust без регулярных выражений — ускорение обработки вывода в 50–100 раз.

### 👁️ Zero-Disk I/O предпросмотр
- **Интерактивный PreviewPanel**: просмотр кадров видео перед сжатием с генерацией через stdout pipe в память без создания временных файлов на диске.

### 🖱️ UX, Drag & Drop и интеграция с ОС
- **Dynamic Island Header**: умная плавающая шапка в стиле Dynamic Island с живым статусом очереди, быстрыми действиями и навигацией.
- **Drag & Drop в обе стороны**:
  - Быстрое добавление файлов перетаскиванием в окно приложения с анимированным оверлеем.
  - **Drag Out**: прямое перетаскивание готового сжатого файла из карточки очереди в Telegram, Discord, папки проводника и любые другие программы (через `tauri-plugin-drag`).
- **Интеграция с проводником Windows**: добавление пункта «Сжать в Szhimatar» в контекстное меню файлов, выделение файла в папке (`explorer /select`), копирование готового файла в буфер обмена.

### 🎨 Оформление и персонализация
- **15 встроенных тем**: Light, Dark Red, Dark Blue, Dark Gray, Dark Green, Dark Orange, AMOLED Night, Blue Ocean, Graphite Light, Mint Glass, Nord Soft, Paper Sepia, Pink, Purple-Pink, Sunny Yellow.
- **Ауры вендоров и свечение курсора**: интерактивные эффекты подсветки с аппаратными оттенками.
- **Performance Mode**: режим высокой производительности с отключением ресурсоемких визуальных эффектов для слабых компьютеров.
- **Анимации переходов**: выбор стилей анимации экранов на базе Framer Motion.
- **7 языков**: Русский, English, 中文 (Chinese), Esperanto, Medžuslovjanski, Взрывной сленг, пустой шаблон перевода.

### 📊 Аналитика и пресеты
- **Панель статистики**: сводная информация по рендерам, процент успешных задач, графики, общий объем сэкономленного дискового пространства и экспорт отчетов (JSON/CSV) — см. [STATISTICS_GUIDE.md](STATISTICS_GUIDE.md).
- **Менеджер пресетов**: создание и сохранение собственных пресетов кодирования, назначение дефолтного пресета при старте приложения.
- **Встроенный автообновлятор**: проверка новых релизов через GitHub Releases и установка обновления в один клик — см. [UPDATER.md](UPDATER.md).

## 🚀 Запуск и сборка

### Требования

- **Node.js** 18+ и npm
- **Rust** 1.70+ (установить через [rustup](https://rustup.rs/))
- **Windows**: Visual Studio C++ Build Tools (компоненты C++ Desktop Development)
- **FFmpeg & FFprobe**: должны быть установлены в системе или указаны в настройках приложения

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run tauri dev
```

### Сборка релизной версии

```bash
npm run tauri build
```

Собранный `.msi` и исполняемый файл будут находиться в `src-tauri/target/release/bundle/`.

## 🧪 Тестирование и отладка

### UI с эмуляцией оборудования (Hardware Override)
Для проверки отображения интерфейса под разные связки CPU/GPU (например, Intel CPU + NVIDIA GPU) без наличия реального «железа»:

```powershell
# Создать конфиг из примера
Copy-Item .hardware-override.example.json .hardware-override.json

# Указать enabled: true и нужные вендоры в .hardware-override.json
# Запустить приложение
npm run tauri dev
```
*Подробнее: [HARDWARE_OVERRIDE_QUICKSTART.md](HARDWARE_OVERRIDE_QUICKSTART.md)*

### Headless FFmpeg тестовый стенд
В репозитории есть изолированный CLI-инструмент для массового бенчмарка параметров сжатия без запуска UI:
```bash
cd test-compressor
npm install
npm start
```
*Подробнее: [test-compressor/README.md](test-compressor/README.md)*

### Запуск тестов
```bash
# Запуск unit-тестов фронтенда и планировщика (Vitest)
npm run test

# Запуск тестов бэкенда (Rust)
cd src-tauri
cargo test
```

## 📁 Хранилище данных

Все пользовательские данные хранятся локально:

- **Windows**: `%USERPROFILE%\.szhimatar\` (обычно `C:\Users\<username>\.szhimatar\`)
- **Linux/macOS**: `~/.szhimatar/`

```
.szhimatar/
├── logs/
│   ├── app.log              # Общий лог приложения
│   └── renders/             # Логи отдельных заданий FFmpeg
├── stats/
│   └── stat.json            # История и статистика сжатий
├── presets/                 # Пользовательские пресеты
├── binaries/                # Локальные бинарники (yt-dlp и др.)
└── settings.json            # Настройки программы
```

## 🎯 Принципы проекта

1. 🔒 **100% Privacy & Offline First**: сжатие видео происходит локально, никаких внешних облаков или трекеров.
2. ⚡ **Максимальная производительность**: мгновенный отклик UI, zero-allocation парсеры и параллельный рендеринг CPU + GPU.
3. 🪶 **Легковесность**: компактный размер исполняемого файла благодаря Tauri и отказ от тяжелых фреймворков.
4. 🧼 **Надежность процессов**: чистый запуск и гарантированное завершение дочерних кодеров без утечек ресурсов.
